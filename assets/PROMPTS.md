# 豆包素材生成提示词（dsh-ai-diary 配套）

直接复制「提示词」代码块到豆包。方括号 `[...]` 处自己替换。

**通用设置**
- 图片：豆包 → 图像生成 → 高清 2K 以上；立绘用 **3:4**，背景/封面用 **16:9**
- 视频：豆包 → 视频生成 → **图生视频**（先传对应立绘/背景图），5–10 秒，**16:9 / 1080P**
- 一次只生成一张/一段，别把多条提示词塞进同一个请求
- 生成后按文末「导入插件」命名放好

## A. 照片 / 立绘

### A1 · 透明底 Q 版二头身立绘（最推荐先补）

> 用途：替换现有 16 张三头身素材，做成参考图那种圆润二头身，且没有白底残线。

```text
生成一张完整的二次元角色全身立绘，Q 版二头身，大头小身体，头身比约 1:1.2，圆润饱满的轮廓。
角色：[蓝发鲸鱼娘，蓝色渐变长发，头顶一根呆毛，头两侧有鲸鱼头鳍，身后一条大鲸尾，深蓝色女仆长裙配白色荷叶边围裙，围裙上绣一只小鲸鱼，白色短袜，深蓝小皮鞋]。
表情：微微张嘴笑，眼睛大而明亮，双手向两侧摊开做介绍姿势，正面站立，双脚并拢。
画风：日系赛璐璐+水彩淡彩混合，干净线稿，柔和明暗，高完成度同人立绘。
背景：纯白色 #FFFFFF 平铺，整张图只有人物，不含任何其他元素。
严格要求：不要圆角卡片、不要边框、不要投影、不要阴影块、不要文字、不要水印、不要签名、不要其他人物、不要背景装饰、不要渐变背景。人物完整不被裁切，四周留 5% 白边。
输出 PNG，分辨率不低于 1536x2048。
```

> 替换角色时只改方括号。8 个角色依次：GPT 白龙娘（银白发/龙角/白鳞龙尾/白金长裙）、Claude 克劳姬（橙发/向日葵发饰/抱书）、Gemini 猫娘（蓝紫发/猫耳猫尾/异色瞳/星芒）、Grok（金发双马尾/蝠翼小冠/黑金哥特裙/X 纹双刃斧）、GLM（黑长发/Z 字挂牌/Z 标黑书/黑白洋装）、Qwen（蓝紫发侧编发/折扇/盘扣/几何徽章）、Kimi（银紫发/月牙/五线谱/K 字牌带蓝点/长笛）。

### A2 · 同姿势表情差分（4 张，一张一条）

> 用途：让日记片能随情绪换表情。原片没有表情差分，这是增强项，不是必需。

```text
在参考立绘的基础上，只修改面部表情，其他完全一致：发型、发饰、服装、姿势、手势、身体角度、画面构图、画风、配色、光源、背景全部保持一模一样。
本张表情：[低落：眼睑下垂，嘴角微微向下，眼神失焦，没有眼泪]。
Q 版二头身，正面站立，纯白背景 #FFFFFF，不要边框/投影/文字/水印，人物完整不裁切，PNG 高清。
```

> 四张依次替换：`低落（如上）`、`慌张：眼睛睁大、眉头抬高、嘴微张、脸颊一小滴汗`、`平静：嘴角放平、眼神温和、无夸张表情`、`释然微笑：眼睛微弯成月牙、嘴角上扬、脸颊淡红晕`。

## B. 视频片段

> 当前插件是**静态立绘 + 代码动效**，不调视频生成模型。下面这些片段用于**后期在剪辑软件里替换或叠加**（片头、片尾、转场、立绘微动层），不是插件直接吃进去的素材。生成时统一 5–10 秒、16:9、1080P、可循环。

### B1 · 立绘微动循环（最重要）

```text
图生视频：以这张 Q 版角色立绘为首帧，让角色做非常轻微的自然待机动作。
动作：缓慢呼吸使肩膀与裙摆起伏约 2–3 像素，眨眼一次，发梢与裙摆末端轻微飘动，手指小幅摆动。
镜头完全固定，不推不拉不摇，人物位置、大小、构图、光线、颜色全程不变，背景保持纯白不变。
动作幅度极小、速度慢、循环首尾无缝。不要转身、不要走动、不要变形、不要换表情、不要镜头运动、不要出现文字或特效。5 秒。
```

### B2 · 深蓝星空动态背景

```text
图生视频：以这张深蓝星空背景为首帧，做几乎察觉不到的氛围动态。
星点极缓慢地明暗闪烁，右下蓝色光晕轻微呼吸，画面里出现 8–12 个很小的白色光点从下往上缓慢漂浮并在中途淡出。
镜头固定，整体色调不变，不要流星、不要镜头运动、不要文字、不要人物、不要快速闪动。8 秒，可循环。
```

### B3 · 暖米色封面动态背景

```text
图生视频：以这张暖米色同心圆背景为首帧，做极轻微的氛围动态。
右侧大圆的光晕缓慢明暗呼吸，内侧细圆环极慢地旋转（10 秒转不超过 5 度），4–6 朵小橙花从画面上方缓慢飘落并淡出。
```

## C. 导入插件

| 素材 | 放哪 | 命名 |
|---|---|---|
| 角色立绘 | `assets/characters/` | `<id>_chibi.png` / `<id>_adult.png` |
| 表情差分 | `assets/characters/` | `<id>_chibi_low.png` / `_panic.png` / `_flat.png` / `_smile.png` |
| 背景图 | `assets/backgrounds/` | `warm-card.png` / `night-sky.png` |
| 视频片段 | `assets/clips/` | 任意，供后期剪辑使用 |

- 角色图片追加/替换后，在 `assets/characters/characters.json` 的对应 `files` 里补上新键；重跑 `python scripts/prepare_assets.py` 会重建清单（注意它会覆盖手改内容）。
- **背景必须是纯白 #FFFFFF，且不能有圆角卡片、边框、投影** —— 现有 `prepare_assets.py` 用「边界连通域 flood-fill」抠白底，这三点做到就不会有残线。若豆包只能给带边框的图，用 `--template=night` 之类也救不了，最好重生成。
- 表情差分的 `mood → 图片` 映射目前还没接（当前 `mood` 只驱动浮动、光晕、背景与光点）；补齐素材后我可以接上。
- 视频片段目前**不进渲染管线**，只作为后期素材；想让插件直接合成，需要再加一段本地 ffmpeg 叠加逻辑。
