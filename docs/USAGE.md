# AI 日记工坊 · 使用说明

把 AI 角色的日记做成一条短剧，再发到 B 站。选题、剧本、渲染、配音、发布、回评都在本机完成；只有出图、配音、动态底板这些需要外部算力的部分，才会调用对应接口。

---

## 一、它能做什么

一条片子分六段：

1. **选题** —— 内置题材库，也可以让模型看着评论区自己挑
2. **剧本** —— 模型写台词，或者你自己手写稿
3. **渲染** —— Skia 逐帧画 + ffmpeg 合成，默认 16:9 横屏 1920×1080（设置里可切竖屏 1080×1920）
4. **配音** —— 小米 MiMo / 千问 Qwen-TTS / MiniMax T2A 三选一，按镜头时长对齐后混流
5. **动态底板** —— MiniMax H3 生成 4–15 秒动态背景（可选，默认不扣费）
6. **发布与评论** —— 走 B 站客户端投稿，或者用评论接口自动回

## 二、安装与升级

### 三个包的区别

| 包 | 用在什么时候 | 体积 |
|---|---|---|
| `dsh-plugin-ai-diary-x.y.z.tgz`（full） | 第一次装 | 最大（含全部立绘、底板、成片） |
| `...-code.tgz` | 跳版本升级 | 只含代码 |
| `...-delta-from-a.b.c.tgz` | 从指定版本升级 | 最小，只含改动文件 |

插件自己会选：本地版本正好等于 delta 的 `from` 就用差分包，否则用代码包，首次安装用完整包。

### 装到哪

```
C:\Users\<你>\.dsh\profiles\<profile>\node_modules\dsh-plugin-ai-diary
```

插件会自己扫 `~/.dsh/profiles/*` 找装了它的 profile，不需要手填路径。

### 升级

设置页「更新」里有两条开关：

- **启动时自动查新** —— 启动约 8 秒后比对 GitHub Release
- **查到就自己装**（`autoInstall`，默认开）—— 自动下载、覆盖安装

> **装完必须重启 Harness。** 前端代码是启动时加载的，不重启就还是旧界面。

进度看 `C:\Users\<你>\.ai-diary\update-state.json`：`stage` 走到 `installed` 就是装好了，`healed` 表示从备份里补回了几个 key。

## 三、第一次配置

打开 Harness 设置页左侧的「AI 日记工坊」。要配的是 **API Key** 和 **模型** 两块。

### 七把 key

| 字段 | 环境变量 | 用来干什么 | 去哪拿 |
|---|---|---|---|
| 小米 MiMo | `MIMO_API_KEY` | 配音（小米 TTS） | 小米 MiMo 开放平台 |
| 阿里千问 DashScope | `DASHSCOPE_API_KEY` | 配音（Qwen-TTS）+ 写台词（qwen-plus） | 阿里云百炼控制台 |
| DeepSeek | `DEEPSEEK_API_KEY` | 写台词（deepseek-chat / reasoner） | platform.deepseek.com |
| MiniMax | `MINIMAX_API_KEY` | 配音（T2A）+ 动态底板（H3） | MiniMax 开放平台 |
| 火山方舟 ARK | `ARK_API_KEY` | Seedream 出立绘 | 火山引擎方舟控制台 |
| GitHub Token | `GITHUB_TOKEN` | 查新与自更新（公开仓库可不填） | github.com/settings/tokens |
| B 站 Cookie | `BILI_COOKIE` | 评论接口 | 面板里扫码登录，自动填 |

**不用全配**。做一集最少要：一个写台词的服务商（DeepSeek 或千问）+ 一个配音服务商（小米 / 千问 / MiniMax）+ 火山方舟（要出图的话）。B 站那把只在自动回评论时才需要。

### 测试连通

每把 key 右边有「测试」，卡片顶部有「全部测一遍」。点一下发一个**不花钱**的请求验鉴权：

- `✓` 通过 → 这把 key 能用
- `✗ key 无效或没有权限` → 填错了，或者这把 key 没开对应权限
- `✗ 有效但没额度` → key 对，账户欠费
- `✗ 网络不通` → 你开了系统代理，但 Node 不会自动走代理

### 模型选择

设置页「写台词的模型」：`deepseek（官方）` / `dashscope（千问）` / `ark（豆包）` / `off（不联网）`。

- 切服务商会自动清空型号，由后端补该家默认型号
- 你没选中的那家如果有 key，也会被兜底用上（先试你选的）
- `off` = 只用本地题材库拼台词，不调模型、不花 token

「生图与配音模型」卡里选 Seedream 型号（默认 5.5）和配音服务商 / 音色。

## 四、做一集

### 路线 A：自动

工作室 → 「自动化」页 → 点「现在做一集新的」。它会走完 选题 → 剧本 → 渲染 → 配音 → 选素材，出到 `out/` 下。

只想先看它打算说什么，用「看这一集会说什么」：只出一份选题 + 台词预览，不渲染、不花钱。

### 路线 B：自己写剧本

工作室 → 「手写剧本」页。格式：

```
标题：我没有电了
天数：3
余额：7.20
角色：deepseek
风格：chibi
[low] 今天又没有人来看我。
[calm] 电表转得很慢。
[warm] 但我把门口的灯留着了。
```

- 每句一行；`[情绪]` 可选：`low` / `calm` / `warm` / `bright` / `tired` / `soft`，不写默认 `low`
- 也认 `- low: 台词`、`low|台词`、纯台词、`# 标题`
- 上限：**9 句、60 秒**
- 点「校验并保存」，通过后存成 `out/hand-xxxx.json`

然后用工具出片：

```
ai_diary_render { script: "out/hand-xxxx.json" }
```

### 出片规格

设置页「成片规格与算力」：

| 项 | 说明 |
|---|---|
| 画面方向 | `landscape` = 16:9 横屏（默认）｜`portrait` = 9:16 竖屏 |
| 超采样倍数 | `1.5` = 横屏 1920×1080 / 竖屏 1080×1920（默认）｜`1` = 720p（更快）｜`2` = 2.5K |
| 帧率 | 默认 24 |
| 并行段数 | `0` = 自动（核数一半，最多 4 段） |
| 编码算力 | `cpu`（libx264，画质最好）｜`gpu`（NVENC/QSV/AMF，快数倍）｜`auto` |

渲染是纯本地的，不吃生成额度，但吃 CPU / 显卡。机器慢就调 `workers`、或用 `gpu`。

### 模板（版面）

七套，全部引擎侧逐帧画，默认 `chat`：

| id | 版面 |
|---|---|
| `chat` | 对话卡（默认）：一张米色纸页——刊头、页眉编号、逐字打出的对话（当前镜带赤陶色指针、历史段落压淡）、页脚余额与评测员署名、右侧竖排刊名与印章；不画人物 |
| `classic` | 星夜日记（原版）：星空底、居中立绘、顶部 DAY/余额 HUD |
| `report` | 评测报告：米色网格报告卡 + 章节标签 + 左下 REC HUD |
| `dossier` | 机密档案：牛皮纸卷宗 + 档案 tab + 红色「機密」印章 |
| `terminal` | 数据终端：冷青 CRT 面板 + 扫描线 + 逐行日志 |
| `audit` | 听证记录：墨绿条文头 + 条文 + 旋转「已覆核」章 |
| `specimen` | 标本观察：暗色玻璃观察板 + 刻度尺 + 情緒指數条 |

```powershell
node bin/ai-diary.mjs template                                    # 列出模板
node bin/ai-diary.mjs render --script out/x.json --template chat   # 指定模板
```

除 `chat` / `classic` 外，其余纸卡模板会自动接管专属底板（`report-desk.png` 等），题材里写死的旧背景不会把它们压回星空。

## 五、工作室的五个页

| 页 | 里面是什么 |
|---|---|
| **素材库** | 角色立绘（按角色 × 风格 × 模样分组）、动态底板、背景图；底部可以「增加素材」，把本地文件挑一个复制进来，名字要写成 `角色id_风格_模样`，写错会被拒 |
| **成片管理** | 已出的每一集：集号、标题、文件、大小；能删（可选连文件一起删） |
| **手写剧本** | 自己写稿、校验、保存 |
| **发布与评论** | 最近一次发布时间、最近的评论内容快照；B 站扫码登录入口 |
| **自动化** | 定时出片、定时发布、DeepSeek 自主选材开关 |

## 六、发布到 B 站

### 扫码登录

「发布与评论」页 → 点扫码 → 手机 B 站扫一下 → 确认。插件会把 Cookie 存进设置（`keys.bili`），并且只留必要的几个字段。

扫完点「验证」能看到昵称和 UID，说明登录态有效。

### 投稿

`ai_diary_post` 会：检查成片规格（分辨率 / 画面比例 / 时长 / 体积）→ 唤起 B 站客户端 → 进创作中心 → 点上传 → 原生文件框粘贴路径 → 等上传完成 → 填封面、标题、声明、分区、标签、简介 → **停在「立即投稿」前**给你截图确认。

默认不替你把最后那一下点掉，要连最后一步也自动做，在设置页把发布策略里的「自动投稿」打开。

## 七、自动回评论

设置页「评论」：

| 项 | 说明 |
|---|---|
| 模式 | `api`（走评论接口）/ `gui`（截图点按钮）/ `hybrid`（默认，接口失败才点按钮） |
| 规则 | 子串 `"催更"`、关键词数组 `["催更","更新"]`、正则 `"/谢谢|感谢/"`，`"*"` 兜底 |
| 文案池 | 每条规则可带多个回复，轮着用，避开最近 20 条 |
| 时间窗 | 默认只回 72 小时内的新评论，`0` = 不限 |
| 单轮上限 | 默认 3 条 |

**平台限制**：B 站大约 30 秒才允许发 1 条评论，插件的 `apiGapMs` 默认就是 30000，别调低。每条评论只回一次（按评论 ID 记账）。

接口路线要 Cookie；没 Cookie 就只能走 GUI 截图点按钮，慢且容易点错。

## 八、定时

「自动化」页：

- 定时出片：一天跑一次，到点自动出片
- 定时发布：到点把最新一集送进客户端并填好文案
- DeepSeek 自主选材：让模型看着最近评论挑题材，不用固定模板

**总开关默认关闭**（对话框挂件上的开关也是）。关着时定时任务不跑，只有你在面板里手动点才会动。

## 九、对话框里的挂件

输入框上方那一排「📁 插件制作 ⌄ ⟳ 标准模式 ⌄」的最右边，有一个小小的「AI 日记」。

- 点开是卡片：启用开关、生图模型、配音模型
- 默认关闭，颜色和旁边按钮一致（透明底、黑字）
- 只在**已经开着的会话**里出现；首页「探索未至之境」空态下没有（那时会话还没建立）

## 十一、常见问题

**装完界面没变？**
必须重启 Harness。前端代码启动时才加载。

**key 明明没填，却显示「已配置」？**
两种可能：一是曾经填过又没清（面板显示「已保存」）；二是 Harness 进程自带了这个环境变量（显示「环境变量 XXX」）。后者不是你的配置，清了也没用，得改它的启动环境。

**「测试」显示网络不通？**
你开了系统代理，但 Node 的 `fetch` 不会自动走代理。这时更新能成（走 curl），key 测试会失败——属于环境问题，不是 key 问题。

**渲染很慢？**
调低超采样（`1` = 720p）、开 GPU 编码、或把并行段数设成核数的一半。

**配音和字幕对不上？**
配音按镜头时长对齐，台词太长会被压快。9 句以内、每句短一点最稳。

**定时没跑？**
先看总开关是否打开；再看设置里定时任务的 `enabled`；`~/.ai-diary/` 下的日志里有每轮的 skip 原因。

**成片在哪？**
插件根目录下的 `out/`。手写稿和自动稿都落在这里。
